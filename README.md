# HOTEL-FACILE-PROYECT

## Descripción del proyecto

BookingSoft es un sistema de gestión hotelera desarrollado para el Apartahotel Facile, ubicado en el barrio El Chicó de Bogotá, Colombia.

El objetivo del sistema es centralizar y automatizar los procesos operativos del hotel, reduciendo errores causados por la gestión manual de reservas y mejorando la eficiencia en la administración de los servicios.

## Problemática

Actualmente, el Apartahotel Facile administra sus operaciones mediante hojas de cálculo en Excel, lo que puede generar inconvenientes como:

* Cruce de reservas.
* Duplicidad de información.
* Falta de control de disponibilidad.
* Procesos manuales en check-in y check-out.
* Dificultad para el seguimiento de mantenimiento y limpieza.

## Objetivo General

Desarrollar una plataforma web que permita gestionar de manera eficiente las reservas, huéspedes, habitaciones y servicios complementarios del Apartahotel Facile.

## Módulos Principales

* Gestión de usuarios.
* Gestión de reservas.
* Check-in y check-out.
* Gestión de habitaciones.
* Mantenimiento.
* Gestión de ama de llaves.
* Reserva de sala de juntas.
* Reserva de coworking.
